# Canvas node, connection and manipulation interactions

Research date: 2026-09-28. Sources are current first-party help, product, release and SDK documentation from Miro, FigJam, Excalidraw, Whimsical, Lucidchart and tldraw. The tldraw section distinguishes its shipped editor primitives from an SDK example that consumers may opt into.

## Finding

Highly regarded canvas editors do not make authors return to a global toolbar for every object. They converge on three complementary creation paths:

1. A toolbar, shape library or keyboard shortcut creates the first standalone node or activates a repeatable node/connector tool.
2. Selecting a node exposes directional quick-add controls. Clicking one creates a nearby node and a bound connection as one operation, usually inheriting the source node's type or style and selecting or editing the new node so the author can continue.
3. Dragging from a node-local connection control creates a connector to an existing node; several products also turn a drop on empty canvas into a new-node prompt.

Miro, FigJam, Whimsical and Lucidchart all implement the selected-node quick-add pattern. Miro's blue-dot action is contextual: it proposes a connection when another object is nearby and otherwise creates a linked copy of the selected object. FigJam exposes four side controls and creates a new shape plus connector, with the text field active. Whimsical's quick-add is always available, works in all directions and reuses the source style. Lucidchart previews the line and shape at each directional node, creates a branch if that direction is occupied, and also offers a shape picker after a manually drawn line is released on blank canvas. [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) · [FigJam quick create](https://help.figma.com/hc/en-us/articles/1500004291601-Build-faster-with-quick-create-in-FigJam) · [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart)

The common direct-manipulation model is equally consistent. Selection reveals a bounding box and only the handles relevant to that object. Nodes drag directly; connection endpoints can be reattached; bound connections follow moved nodes; connector paths expose one or more bend/segment handles; labels can be edited and moved on the path; and shape or line properties appear in a contextual toolbar. Dense or precise operations such as alignment, distribution, auto-layout, type conversion and exact styling remain toolbar or menu actions. [FigJam selection and arrangement](https://help.figma.com/hc/en-us/articles/1500004292221-Select-move-and-order-objects-in-FigJam) · [FigJam connectors](https://help.figma.com/hc/en-us/articles/1500004414542-Create-diagrams-and-flows-with-connectors-in-FigJam) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart) · [Whimsical connectors](https://whimsical.com/learn/boards/connectors)

## Product comparison

### Miro

- The first shape comes from the toolbar or shape panel. After selecting a shape, sticky or card, hovering one of its blue dots previews a smart action. Clicking creates either a nearby connection or a linked copy; dragging draws a connection to a chosen object. `L` activates the connection-line tool. [Miro shapes](https://help.miro.com/hc/en-us/articles/360017730713-Shapes) · [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines)
- A selected connector exposes endpoints and path control points. Authors can drag an endpoint to reattach it, drag white/blue points to reshape the path, double-click a white point to remove an extra bend, add and reposition labels, and insert a new shape into an existing connection from its contextual menu. [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines)
- Node selection exposes corner resize handles, a rotation handle and a contextual object menu. A node can be converted between a shape, sticky, card or text object while retaining text and color where possible. Alignment guides can appear while objects move. [Miro shapes](https://help.miro.com/hc/en-us/articles/360017730713-Shapes) · [Miro switch type](https://help.miro.com/hc/en-us/articles/360017572314-Switch-type) · [Miro objects](https://help.miro.com/hc/en-us/articles/360017730953-Working-with-objects)
- Miro distinguishes dynamic attachment from a fixed side: attaching to the center blue dot lets routing adjust to avoid crossing the moved objects, while attaching to a non-center dot fixes the side and may cause a crossing later. This is close to Manatee's existing Auto versus cardinal dock distinction. [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines)

### FigJam

- Shapes and stickies can be placed from the toolbar, but the fast path starts from a selected object. Hovering a side dot reveals quick create in four directions. For shapes, click or drag creates a new shape and connector with the new text field active. Repeated creation on the same side fans additional shapes above and below the last one. `Control/Command+Enter` creates to the right; it includes a connector for shapes but not for stickies. [FigJam quick create](https://help.figma.com/hc/en-us/articles/1500004291601-Build-faster-with-quick-create-in-FigJam)
- A connector tool supports bent, curved and straight paths and remains active until the user changes tools or presses `V`/`Esc`. Lines snap to shapes and stickies, follow them when moved, and can also remain unattached. Selection exposes endpoint handles for reattachment and path handles for rerouting; holding `Control/Command` while moving an endpoint bypasses side snapping. Labels can be dragged along the path. [FigJam connectors](https://help.figma.com/hc/en-us/articles/1500004414542-Create-diagrams-and-flows-with-connectors-in-FigJam)
- The default select tool uses a blue bounding box. Direct manipulation covers drag-to-move, side and corner resize handles, rotation just outside a corner, and modifier keys for uniform or center-anchored resizing. Multi-selection adds align, tidy-up, spacing and reorder controls directly to the selection. [FigJam selection and arrangement](https://help.figma.com/hc/en-us/articles/1500004292221-Select-move-and-order-objects-in-FigJam) · [FigJam resize and rotate](https://help.figma.com/hc/en-us/articles/1500006206242-Resize-rotate-and-flip-objects-in-FigJam)

### Excalidraw

- Excalidraw keeps a drawing-tool model: shape and arrow tools can be activated by toolbar or keyboard; dragging produces a single line while clicking creates a multipoint line. The official UI strings describe automatic arrow binding, a modifier to suppress binding and another to bind to a fixed point. Current editor state also exposes a user preference for automatic arrow binding and midpoint snapping. [Excalidraw UI strings](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/locales/en.json) · [Excalidraw editor state](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/types.ts)
- Its flowchart fast path is keyboard-led: create a rectangle with `R` or `2`, use `Tab` to change its shape, then press `Control/Command` plus an arrow key on a selected object to create another node in that direction. This is less discoverable than persistent on-canvas plus buttons but exceptionally fast for repeated authoring. [Excalidraw visual brainstorming guide](https://plus.excalidraw.com/use-cases/visual-brainstorming)
- Excalidraw 0.18 introduced flowchart support and elbow arrows. The current Excalidraw+ changelog documents a global binding preference, visible binding midpoint indicators, non-elbow snapping, and enhanced endpoint/text interactions. Its emphasis is adjustable binding inside a general-purpose sketching model, rather than a diagram-only connection workflow. [Excalidraw 0.18 release](https://github.com/excalidraw/excalidraw/releases/tag/v0.18.0) · [Excalidraw+ changelog](https://plus.excalidraw.com/changelog)

### Whimsical

- Adding one shape makes directional quick-add controls available without entering a special mode. Quick add creates an already-connected shape, inherits the preceding shape's style, works with `Option/Alt` plus an arrow key, and can be hidden with `Q`. Holding `Shift` while hovering a quick-add button changes direction. Dragging a quick-add control instead of clicking it draws a custom connector. [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Whimsical shortcuts](https://whimsical.com/learn/shortcuts/mac) · [Whimsical quick-add release](https://whimsical.com/releases/2)
- Connectors attach when the target receives a purple highlight. Selection supports independent start/end marker styles, elbow or curved routing, whole-line dragging, editable/repositionable labels and navigation from one endpoint to the other. In 2026 Whimsical added visible exact attachment points, persistent connection control-point handles for elbow and curved connectors, and snapping between nearby elbow segments. [Whimsical connectors](https://whimsical.com/learn/boards/connectors) · [Whimsical connector improvements](https://whimsical.com/releases/2026-2-command-menu-and-colors)
- A contextual bar supplies shape and connector properties. Multi-selected connected shapes can be auto-laid out horizontally or vertically; the operation rearranges nodes and reroutes connectors. This is an explicit tidy-up command, not an automatic reaction to every edit. [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Whimsical auto-layout release](https://whimsical.com/releases/2026-4-flowchart-auto-layout)

### Lucidchart

- Lucidchart offers the broadest creation funnel. Authors can drag a shape from the library, drag a line from a selected node to an existing node, click a directional quick-add preview to create a line and shape, or drop a line on blank canvas and choose the new shape from an auto-prompt. Quick add uses available space in the chosen direction and branches when that direction is occupied. The blank-drop auto-prompt can be disabled in document settings. [Lucidchart shapes](https://help.lucid.co/hc/en-us/articles/16390096079764-Add-and-customize-shapes-in-Lucidchart) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart)
- Bound lines follow moved objects. A smart line can attach dynamically to the target outline and choose an efficient path; a selected endpoint can instead be dragged to a precise location on a shape. Elbow paths show a node at each section midpoint and another on hover at a quarter point; dragging one creates a persistent anchor. Straight and curved lines expose a center control that splits into more editable sections. Individual joints or the entire route can be reset. [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart)
- Direct manipulation is supplemented with operations for diagram maintenance: insert space by pressing `X` and dragging, auto-layout to grid or hierarchy, match size, group, change shape, and set a selected shape as the default style for future nodes. [Lucidchart flowcharts](https://help.lucid.co/hc/en-us/articles/16300314888724-Create-a-flowchart-in-Lucidchart)

### tldraw

- The shipped editor has separate select, hand, draw, arrow, line, geo, text and note tools. Selection drives movement, resize, rotation and other transforms. Single-shape selection exposes shape-specific handles: arrows have endpoint handles, lines have vertex and point-creation handles, and notes have clone handles for quick duplication. Binding-hint and snapping overlays provide feedback while an arrow endpoint is dragged. [tldraw tools](https://tldraw.dev/docs/tools) · [tldraw handles](https://tldraw.dev/docs/handles) · [tldraw overlays](https://tldraw.dev/sdk-features/overlay-utils)
- Arrow attachment is a persistent binding at each terminal, so the arrow follows either shape when it moves. Bindings can target a precise normalized anchor or allow the route to aim at the shape center and stop at its outline. [tldraw arrow example](https://tldraw.dev/examples/create-arrow)
- tldraw documents a four-direction connected-shape affordance as an SDK customization, not as a claim about the default editor. Its example renders fixed-screen-size buttons outside a selected shape, duplicates the source in the chosen direction, creates a bound arrow, selects the new shape for repeated expansion and records the whole operation as one undo step. It hides the buttons during movement, resizing or pointer activity. This is strong implementation evidence for the pattern while remaining a deliberate product choice for Manatee. [tldraw connected-shape example](https://tldraw.dev/examples/add-connected-shape)

## Source caveats

Whimsical's current first-party pages contain several small inconsistencies, so the comparison above uses only the behavior on which the sources agree. The flowchart guide says `S` opens diagram shapes, while the current shortcut tables assign `S` to other mode-specific tools and omit it from diagram shortcuts. The shortcut table still lists `Q` as **Hide quick add**, while a later release says quick-add is “always on”; the safest reading is that no separate quick-add mode is required, but its affordances can be temporarily hidden. The connector help page describes elbow or curved routing, while the newer 2026.2 release explicitly refers to elbow and “straight/curved” connectors; the newer release is the better evidence for current geometry. `L` is also overloaded between line and connector contexts, so `C` is the only unambiguous connector shortcut. [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Whimsical Mac shortcuts](https://whimsical.com/learn/shortcuts/mac) · [Whimsical PC shortcuts](https://whimsical.com/learn/shortcuts/pc) · [Whimsical quick-add release](https://whimsical.com/releases/2) · [Whimsical connectors](https://whimsical.com/learn/boards/connectors) · [Whimsical connector improvements](https://whimsical.com/releases/2026-2-command-menu-and-colors)

Excalidraw's most precise interaction evidence is split between its open-source UI strings/editor state and its hosted-product guidance and changelog; the latter can include Excalidraw+ changes ahead of, or separate from, the tagged open-source editor. The recommendation therefore relies on Excalidraw mainly as evidence for a keyboard-first flowchart path and user-controllable arrow binding, not as proof that every listed Plus interaction is present in every open-source deployment. [Excalidraw UI strings](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/locales/en.json) · [Excalidraw editor state](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/types.ts) · [Excalidraw+ changelog](https://plus.excalidraw.com/changelog)

## Common patterns worth carrying into Manatee

1. **Use progressive creation.** Keep the existing create entry point for an empty document, then make a selected node the launch point for subsequent authoring. Four directional controls are the most predictable baseline; they should be screen-sized rather than shrinking with canvas zoom, and should disappear while the selection is moving or resizing. Miro, FigJam, Whimsical and Lucidchart all validate the interaction; tldraw's implementation example validates fixed-screen placement and state-dependent visibility. [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) · [FigJam quick create](https://help.figma.com/hc/en-us/articles/1500004291601-Build-faster-with-quick-create-in-FigJam) · [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart) · [tldraw connected-shape example](https://tldraw.dev/examples/add-connected-shape)
2. **Make click and drag related but distinct.** Clicking a node-side control should create a sensible default node plus connection in that direction. Dragging should draw a connection to an existing target; dropping on blank canvas can open a compact node-type chooser and then create both records. This combines the low-friction FigJam/Whimsical action with Lucidchart's explicit blank-drop choice and preserves a direct way to connect existing objects. [FigJam quick create](https://help.figma.com/hc/en-us/articles/1500004291601-Build-faster-with-quick-create-in-FigJam) · [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart)
3. **Treat create-and-connect as one command.** The node, relationship, initial position and selection change should form one undoable operation. The new node should become selected with label editing active, so repeated quick-add never requires a trip through the Inspector. FigJam does this in the product; tldraw's example explicitly wraps duplication and binding in one undo transaction. [FigJam quick create](https://help.figma.com/hc/en-us/articles/1500004291601-Build-faster-with-quick-create-in-FigJam) · [tldraw connected-shape example](https://tldraw.dev/examples/add-connected-shape)
4. **Inherit narrowly.** A quick-created node should inherit the source node's family/shape and the effective visual style that a person would perceive, but receive a new identity and neutral/default semantic attributes. Whimsical explicitly carries style forward, Miro creates the same linked object type, and tldraw's example duplicates the source and copies its color to the arrow. [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) · [tldraw connected-shape example](https://tldraw.dev/examples/add-connected-shape)
5. **Keep attachment and routing concepts separate.** Dragging an endpoint changes semantic source/target only when it lands on another node; dragging among north/east/south/west targets changes the presentational dock; dragging a path segment changes routing geometry, if Manatee later stores it. Miro's dynamic-center versus fixed-side attachment, FigJam's side snap bypass, and Lucidchart's smart versus precise endpoint behavior all expose this distinction. [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) · [FigJam connectors](https://help.figma.com/hc/en-us/articles/1500004414542-Create-diagrams-and-flows-with-connectors-in-FigJam) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart)
6. **Reserve persistent handles for the selected item.** Hover may reveal the four create/connect affordances around the selected node, but resize, rotate, endpoint and path handles should appear only after selection. This preserves the low visual noise common to the products and gives touch users stable targets. [FigJam selection and arrangement](https://help.figma.com/hc/en-us/articles/1500004292221-Select-move-and-order-objects-in-FigJam) · [tldraw handles](https://tldraw.dev/docs/handles) · [Whimsical connector improvements](https://whimsical.com/releases/2026-2-command-menu-and-colors)
7. **Add layout repair as an explicit operation.** Alignment guides during movement, multi-select align/distribute, insert-space and opt-in auto-layout help authors recover from local edits without letting the engine unexpectedly rearrange the entire diagram. Miro uses movement guides, FigJam exposes tidy-up and live gap controls, Lucidchart offers insert-space and auto-layout, and Whimsical reroutes connectors after an explicit flowchart layout command. [Miro objects](https://help.miro.com/hc/en-us/articles/360017730953-Working-with-objects) · [FigJam selection and arrangement](https://help.figma.com/hc/en-us/articles/1500004292221-Select-move-and-order-objects-in-FigJam) · [Lucidchart flowcharts](https://help.lucid.co/hc/en-us/articles/16300314888724-Create-a-flowchart-in-Lucidchart) · [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts)
8. **Provide keyboard parity without taking Manatee's existing move chord.** Whimsical uses `Option/Alt+Arrow` and Excalidraw uses `Control/Command+Arrow` for directional creation; Manatee already uses `Alt/Option+Arrow` to move a selected node. Prefer a discoverable `Control/Command+Enter` default-direction action like FigJam, plus named directional commands in the command surface, instead of overloading the established move shortcut. [Whimsical shortcuts](https://whimsical.com/learn/shortcuts/mac) · [Excalidraw visual brainstorming guide](https://plus.excalidraw.com/use-cases/visual-brainstorming) · [FigJam quick create](https://help.figma.com/hc/en-us/articles/1500004291601-Build-faster-with-quick-create-in-FigJam) · [Manatee authoring](../studio.md)

## Important product divergences

- **Predictive versus explicit next-node type.** Miro predicts either a connection or same-type object from proximity; FigJam and Whimsical optimize for a same/similar next object; Lucidchart asks from an auto-prompt after blank-drop. A specialized diagram editor needs the explicit chooser sooner than a generic whiteboard if node notation changes semantics. [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) · [FigJam quick create](https://help.figma.com/hc/en-us/articles/1500004291601-Build-faster-with-quick-create-in-FigJam) · [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart)
- **Freeform binding versus diagram-first attachment.** Excalidraw lets authors suppress or fix automatic binding because arrows are also independent drawing objects. FigJam and Lucidchart also allow unattached lines, while their fast paths favor bound connectors. Manatee's authored relationships are semantic; a dangling connector should therefore be a temporary creation state, not a saved relationship. [Excalidraw UI strings](https://github.com/excalidraw/excalidraw/blob/master/packages/excalidraw/locales/en.json) · [FigJam connectors](https://help.figma.com/hc/en-us/articles/1500004414542-Create-diagrams-and-flows-with-connectors-in-FigJam) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart)
- **Automatic versus manual route ownership.** Most products continuously reroute bound connectors but also expose manual bend handles. Manatee currently persists endpoint docks but delegates the remaining route to its renderer. Full waypoint editing would introduce a new persistence and reconciliation contract; it is not required for an initial node/connection authoring interface. [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart) · [Manatee authoring](../studio.md)
- **Graph expansion versus canvas-object creation.** tldraw's four-button connected-shape UI is an SDK example layered on generic shape primitives, whereas Miro, FigJam, Whimsical and Lucidchart ship comparable graph-expansion behavior. Manatee can implement the narrower diagram-first behavior without adopting a general drawing-object system. [tldraw connected-shape example](https://tldraw.dev/examples/add-connected-shape) · [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) · [FigJam quick create](https://help.figma.com/hc/en-us/articles/1500004291601-Build-faster-with-quick-create-in-FigJam) · [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts) · [Lucidchart lines](https://help.lucid.co/hc/en-us/articles/16157138194836-Add-and-style-lines-in-Lucidchart)

## Recommended first increment for Manatee

Add four zoom-independent create/connect handles to a single selected node on desktop and sufficiently large equivalent controls on touch. A click creates a same-family node in that direction, creates the default relationship, chooses a collision-free initial position, selects the new node and starts label editing. A drag connects to an existing node; a blank drop opens a small type/notation chooser and then creates the node and relationship atomically. Hide the handles during dragging, resizing, source-invalid states and whenever structural editing is disabled.

Keep the existing Inspector for semantic type, notation and advanced properties, but add selection-local resize handles for node types that the source format can represent safely. Continue using direct node drag and the existing connection endpoint controls. Defer freeform waypoints, rotation, arbitrary unbound lines and general canvas-object tooling; they would widen Manatee's document contract without being necessary to achieve the fast graph-authoring loop evidenced above.

After the direct creation loop, add three maintenance operations in order: insert a node into a selected connection, align/distribute a multi-selection, and explicit auto-layout for the selected connected subgraph. Each should be a single undoable structural/presentation command and should never run implicitly after an ordinary edit. Miro validates insert-on-connection, FigJam validates selection-local spacing controls, and Lucidchart and Whimsical validate opt-in layout repair. [Miro connection lines](https://help.miro.com/hc/en-us/articles/360017730733-Connection-lines) · [FigJam selection and arrangement](https://help.figma.com/hc/en-us/articles/1500004292221-Select-move-and-order-objects-in-FigJam) · [Lucidchart flowcharts](https://help.lucid.co/hc/en-us/articles/16300314888724-Create-a-flowchart-in-Lucidchart) · [Whimsical flowcharts](https://whimsical.com/learn/get-started/flowcharts)

## Questions the interaction design must settle

1. Does a click always clone the selected node's semantic type, or should decision/event-like nodes instead open the chooser because cloning them can produce invalid or misleading flows?
2. Which default relationship is created for each supported family, and when must the author choose a connection kind before commit?
3. Does dropping on a group or container create inside it, connect to it, or reject the target?
4. When auto-layout still owns a region, does quick add merely add source structure and let layout place it, or also write an initial manual position? If it writes a position, when does that pin become visible and removable?
5. Should node resize be semantic source, Manatee presentation metadata, or unsupported for families whose renderer controls dimensions from label content?
6. On touch, are directional buttons sufficient, or is a press-drag gesture necessary in the first increment to connect existing nodes without a desktop pointer?
